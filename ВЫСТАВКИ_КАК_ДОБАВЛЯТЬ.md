# Как добавить выставку на сайт

## Проще всего — через Дашборд Колыбели

Открой локальное приложение и перейди в **Ссылки и процессы → Мои выставки**. Этот список отображается на страницах **«Художник»**, **«Обо мне»** и в CV. Вставь список целиком, нажми «Разобрать список», проверь названия и маркеры, затем нажми «Опубликовать в GitHub». Если вставляешь только новые события, выбери «Добавить к текущему списку»; для полного списка оставь «Заменить список целиком». GitHub Pages обновится после отправки коммита. Форма меняет только список выставок; GitHub-ключ в браузере не хранится.

Маркер `cmp` означает конкурс, включая премии и опен-коллы. Остальные типы описаны ниже.

## Запасной способ — вручную

Все записи хранятся в `exhibitions.json`. Новый объект можно добавить в начало массива, после открывающей квадратной скобки.

Пример:

```json
{
  "year": 2026,
  "type": "cmp",
  "title": "Название события",
  "detail": "Организатор; город",
  "place": "Москва",
  "url": "https://example.com"
}
```

Обязательные поля: `year`, `type`, `title`, `detail`, `place`. Поле `url` можно пропустить, если ссылки нет. После каждой записи, кроме последней, нужна запятая. Не добавляйте `|`: каждое поле записывается отдельной строкой.

Метка `type` задаёт цвет карточки, подпись и фильтр на сайте:

- `cmp` — конкурс, премия или опен-колл
- `exh` — выставка
- `intl` — международная выставка
- `onl` — онлайн-выставка
- `pers` — персональная выставка
- `auc` — аукцион
- `mkt` — маркет

Если работаешь вручную, открой `exhibitions.json` в GitHub, нажми карандаш, добавь запись и сделай Commit changes.
