# Как добавить выставку на сайт

Все записи хранятся в `exhibitions.json`. Добавьте новый объект в начало массива, после открывающей квадратной скобки. После сохранения и отправки изменений в GitHub Pages список обновится на страницах «Художник» и CV.

Пример:

```json
{
  "year": 2026,
  "type": "award",
  "title": "Название премии или выставки",
  "detail": "Организатор; город",
  "place": "Москва",
  "url": "https://example.com"
}
```

Обязательные поля: `year`, `type`, `title`, `detail`, `place`. Поле `url` можно пропустить, если ссылки нет. После каждой записи, кроме последней, нужна запятая. Не добавляйте `|`: каждое поле записывается отдельной строкой.

Метка `type` задаёт цвет карточки, подпись и фильтр на сайте:

- `award` — премия (золотая метка)
- `cmp` — конкурс
- `exh` — выставка
- `intl` — международная выставка
- `onl` — онлайн-выставка
- `pers` — персональная выставка
- `auc` — аукцион
- `mkt` — маркет

Для обновления откройте файл `exhibitions.json` в GitHub, нажмите карандаш, добавьте запись и сделайте Commit changes.
