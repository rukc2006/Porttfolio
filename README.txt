VK
Для доступных выставочных записей добавлена попытка встроить сам пост VK. На опубликованном HTTPS-сайте VK может подтянуть содержимое поста вместе с фотографиями. При открытии локального файла file:// встроенный VK-код не запускается, поэтому вместо ошибки показывается аккуратная обложка с названием записи и ссылкой.

При установке
— заменить корневой index.html;
— добавить/заменить Kcradle.html;
— добавить папку assets;
— добавить/заменить works/index.html;
— НЕ удалять и НЕ заменять существующие sw.js и pack-*.bin.
